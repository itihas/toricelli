Toricelli
===



An experiment in programmable attention: takes a collection of notes and serves them to you in an algorithmically determined feed. The algorithm in question is currently FSRS with PageRank run on top of it.

Working prototype at https://github.com/itihas/toricelli-el; that one Works On My Machine™ for my org-roam setup. This one, ideally, will work in a more note-source-agnostic fashion.

See https://itihas.review/20240905120229-toricelli for the philosophising.
